# 3DES 文件加解密 v1.3.0

信息安全课程实验作品：**纯手写** DES / 三重 DES（3DES-EDE）算法，对任意文件（文本、二进制、中文文件名与中文路径均可）进行加解密。不依赖 OpenSSL、CryptoAPI 等任何现成密码库，也不依赖任何 DLL。

## 本次更新（v1.3.0）—— 界面改版：仿 7-Zip 主窗口

主窗口按 7-Zip 的布局重做，自上而下为 **菜单栏 → 工具栏 → 地址栏 → 文件列表 → 状态栏**，底部另有可折叠的日志面板：

- **工具栏**：打开 / 加密 / 解密 ｜ 信息 / 随机密钥 / 测试 ｜ 关于。图标全部由 GDI 现场绘制（文件夹、带绿色加号的加密包、带红色上箭头的解密包、钥匙、对勾……），悬停与按下带立体反馈并附工具提示，未选中文件时自动灰掉“加密/解密”。
- **地址栏**：仿资源管理器的路径框，可直接输入路径回车跳转，下拉列表给出目录层级，左侧“↑”按钮向上一级。
- **文件列表**：ListView 报表模式，列为 名称 / 大小 / 修改日期 / 属性 / 类型，点列头可排序，双击文件夹进入、双击文件即选中；`..` 行为向上一级。
- **状态栏**：三格分别显示对象数、字节数（选中时显示已选大小）与最近一次操作的提示。

加密与解密的参数从原来的主窗口表单移入两个同样仿 7-Zip 的模态对话框：

| 对话框 | 对应 7-Zip | 内容 |
| --- | --- | --- |
| 添加到加密包… | 添加到压缩包 | 输出文件（预填默认名 + “浏览…”）、加密格式、工作模式、密钥（“随机生成”/“显示密钥”）、覆盖前确认 |
| 解密到… | 提取 | 只需密钥（自动识别密钥长度对应的算法），算法 / 模式 / IV 从密文文件头读取 |

另外，“信息”对话框可解析密文自描述文件头中的算法 / 模式 / IV / 原始长度；“复制到剪贴板”一键带走。“测试”直接运行内置 KAT 自检。快捷键：`Ctrl+O` / `Ctrl+E` / `Ctrl+D` / `Ctrl+K` / `F5` / `F1`。

图形界面端到端测试同步重写并扩充为 **21 项**，覆盖两个对话框的取值与校验、地址栏选文件、列表刷新、日志与信息解析。

## v1.1.0 带来的功能

- **图形界面支持自定义输出路径**：新增“输出文件”一栏与“另存为…”按钮，可把结果保存到任意目录/文件名；默认名仍会按规则预填（加密 `<原文件名>.3des`，解密去掉 `.3des`，无该后缀则追加 `.dec`），清空该栏即恢复自动命名。

## 安装说明

**安装版**：双击 `3DES-FileCrypto-1.3.0-win64-setup.exe`，按向导完成安装。安装后可选择是否加入 PATH —— 加入后在任意目录执行 `tdes genkey` 即可使用。卸载时安装目录会自动从 PATH 中移除。

**便携版**：解压 `3DES-FileCrypto-1.3.0-win64-portable.zip` 到任意目录，双击 `tdes_gui.exe` 即可。

**首次使用**：图形界面里在文件列表中单击 / 双击选文件（或把文件拖进窗口）→ 点“加密”弹出“添加到加密包…”对话框 → 输入 48 个十六进制字符的 3DES-3Key 密钥（或点“随机生成”）→ 点“确定”。解密只需密钥，算法 / 模式 / IV 会自动从密文文件头读取。

## 系统要求

Windows 7 SP1 及以上，64 位。可执行文件已用 `-static -static-libgcc -static-libstdc++` 静态链接，无需安装任何运行库。

## 安全提示

本程序为**教学实现**：DES 有效密钥仅 56 位，早已可被穷举；3DES 因“中间相遇”攻击实际安全强度约 112 位；ECB 模式会泄漏明文分组重复结构。请勿用它保护真实敏感数据，工程场景请使用 AES-GCM 等现代算法。
