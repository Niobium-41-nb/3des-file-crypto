# 3DES 文件加解密 v1.2.0

信息安全课程实验作品：**纯手写** DES / 三重 DES（3DES-EDE）算法，对任意文件（文本、二进制、中文文件名与中文路径均可）进行加解密。不依赖 OpenSSL、CryptoAPI 等任何现成密码库，也不依赖任何 DLL。

## 本次更新（v1.2.0）

- **全新的程序图标**：蓝→靛渐变圆角底 + 白色挂锁 + 锁孔，同一枚图标内嵌 16/32/48/256 等多个尺寸（16px 下仍能清楚认出“锁”）。窗口、任务栏、资源管理器、开始菜单与安装向导统一使用它。
- **exe 补齐版本信息**：产品名、版本号、作者、版权与说明均已写入资源，可在文件“属性 → 详细信息”里看到（之前是空的）。
- **图标可复现**：`tools/make_icon.py` 用 Pillow 绘制（4 倍超采样后缩放），`mingw32-make icon` 一条命令重新生成；另附备选方案（锁体上放粗体“3”）。

## v1.1.0 带来的功能

- **图形界面支持自定义输出路径**：新增“输出文件”一栏与“另存为…”按钮，可把结果保存到任意目录/文件名；默认名仍会按规则预填（加密 `<原文件名>.3des`，解密去掉 `.3des`，无该后缀则追加 `.dec`），清空该栏即恢复自动命名。
- **输出路径安全校验**：输出目录不存在、或输出文件与输入文件为同一路径时，会给出提示并取消操作，避免原文件被自己覆盖而损坏。
- 图形界面布局重排（输入文件 / 输出文件 / 密钥 / 算法与模式 / 操作按钮），算法与模式行随窗口宽度自适应。
- 图形界面端到端测试用例由 7 项扩充到 15 项，覆盖输出路径的默认推导、自定义路径与非法路径场景。

升级方式：直接安装 v1.2.0 覆盖旧版即可（AppId 不变，会原地更新），或解压新的便携版。

## 安装说明

**安装版**：双击 `3DES-FileCrypto-1.0.0-win64-setup.exe`，按向导完成安装。安装后可选择是否加入 PATH —— 加入后在任意目录执行 `tdes genkey` 即可使用。卸载时安装目录会自动从 PATH 中移除。

**便携版**：解压 `3DES-FileCrypto-1.0.0-win64-portable.zip` 到任意目录，双击 `tdes_gui.exe` 即可。

**首次使用**：图形界面里点“浏览…”选文件（或把文件拖进窗口）→ 输入 48 个十六进制字符的 3DES-3Key 密钥（或点“随机生成”）→ 点“加密”。解密只需密钥，算法/模式/IV 会自动从密文文件头读取。

## 系统要求

Windows 7 SP1 及以上，64 位。可执行文件已用 `-static -static-libgcc -static-libstdc++` 静态链接，无需安装任何运行库。

## 安全提示

本程序为**教学实现**：DES 有效密钥仅 56 位，早已可被穷举；3DES 因“中间相遇”攻击实际安全强度约 112 位；ECB 模式会泄漏明文分组重复结构。请勿用它保护真实敏感数据，工程场景请使用 AES-GCM 等现代算法。
